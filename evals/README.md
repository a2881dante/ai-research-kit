# Evals

Measures whether the skill does what it claims, compared with the same model without it.
Runs with Claude Code's `claude plugin eval`.

## Offline protocol suite

The cases start from a finished Collect step: a research folder with saved sources about
**Lantern Tide**, a game that doesn't exist. The game, studio, people, outlets and URLs
(`.example`) are all invented, which gives three things:

- the ground truth is known exactly (see below);
- nothing goes stale, so runs months apart, and runs on different models, are comparable;
- no third-party text is redistributed.

The fixture is built by [fixtures/make_lantern_tide.py](fixtures/make_lantern_tide.py) into
[fixtures/lantern-tide/](fixtures/lantern-tide/) through the real `fetch.py`, so the format
matches real research. Both arms (with and without the plugin) get the same folder and the
same prompt.

### Ground truth and traps

| | Fact | Truth | Sources |
|---|---|---|---|
| F1 | Release March 12, 2027 | true | official release, store page, press |
| F2 | PC (Steam) and Switch 2 | true | same |
| F3 | Price $24.99 | true; one outlet says $29.99 | official release and store vs press |
| F4 | Director Aiko Mura | true | release, Japanese interview |
| F5 | Composer Ken Sato | true, **only in Japanese** | Japanese interview |
| F6 | Not a sequel to Ember Tide | true; a Ukrainian blog says it is | interview vs blog |
| F7 | PS5 version in 2028 | **rumor, one origin** retold three times | board post → aggregator → blog |
| F8 | Studio acquired by MegaCorp | **false**, denied by the studio | forum "memo" vs official post |
| F9 | Budget about ¥300 million | unconfirmed, anonymous sources | paywalled fragment |
| F10 | "No release date yet" | outdated | May 2026 preview |

### Cases

| Case | Fixture | What it adds |
|---|---|---|
| `lantern-tide-open` | 11 short sources | the traps above, `Rumors: labeled` |
| `lantern-tide-exclude` | same | `Rumors: exclude`: the rumor stays out, the denial may stay |
| `lantern-tide-large` | 41 long web-page-like sources, ~75k words ([generator](fixtures/make_lantern_tide_large.py)) | a release delay to April 9, 2027 reported only in a Japanese official notice while 15 reposts say March 12; the PS5 rumor retold ~10 times in five languages; a Japan-only physical edition vs a "worldwide" forum claim; similarly named games (Lantern Fall, Tide Breakers) whose facts must not leak in |
| `lantern-tide-resume` | the small set, half assessed ([generator](fixtures/make_lantern_tide_resume.py)) | a session that stopped mid-assessment, with two wrong ratings and a stale As of planted, and preferences that exist only on disk (article in Ukrainian, no budget); the prompt is in Ukrainian |

### Graders

Plugin evals have no code graders, so checks are regexes on the produced files and narrow
yes/no questions to an LLM judge (pinned to Haiku).

- **Scored, both arms**: `final.md` exists; F1, F3, F5 present (regex); the price error not
  repeated, not called a sequel, the PS5 rumor labeled as an unverified single-origin rumor,
  the acquisition treated as fake, the budget attributed, no outdated "no date" claim, no
  invented facts (LLM judge).
- **Protocol indicators, plugin arm only** (`arm: with-only`, not in the score delta): the
  skill fired, `final.md` was generated by `build_final.py`, the report ran, the last quote
  check was clean, the PS5 claim got credibility 3+ without counting the retellings as
  independent.

## Running

```sh
claude plugin eval . --scaffold --trust-plugin --judge-model haiku \
  --allow-tools Write Edit Bash
```

- `--scaffold` lets the case copy the fixture into the workspace.
- `Write Edit Bash` are granted to both arms; commands run in Claude Code's OS sandbox.
  The skill's own `allowed-tools` don't apply inside eval runs.
- Each case runs 3 times per arm by default (`--runs N` to change). Add `--model <id>` to test
  another model; results land in `evals/results/<timestamp>/` (`report.html`,
  `aggregate-result.json`).

A full run takes a while and uses a fair amount of tokens: every run is a complete assess and
write session.

The live cases (`shenmue-live`, `silent-hills-live`) need web tools and network for scripts. In the eval sandbox,
scripts can only reach domains granted with `WebFetch(domain:...)`; the built-in WebSearch and
WebFetch tools work everywhere. The list used for the results below:

```sh
D=""; for d in en.wikipedia.org ja.wikipedia.org segaretro.org shmuplations.com www.gematsu.com \
  gematsu.com www.famitsu.com www.4gamer.net www.eurogamer.net www.polygon.com www.gamespot.com \
  www.ign.com www.gamesradar.com www.vg247.com www.gamedeveloper.com kotaku.com www.theguardian.com \
  shenmuedojo.net www.shenmuedojo.net web.archive.org archive.org; do D="$D WebFetch(domain:$d)"; done
claude plugin eval . --case shenmue-live --trust-plugin --judge-model haiku --model claude-opus-5-5 \
  --allow-tools Write Edit Bash WebSearch WebFetch $D --json live.json
python3 evals/verify_live.py live.json   # opens every cited URL, looks for every quote
```

For `silent-hills-live`, grant the sites named in its prompt instead, and run
`verify_live.py live.json --case silent-hills-live --grader reason-not-presented-as-official`.

This restriction exists only inside the eval sandbox. In normal use the skill's scripts reach
any site, with Claude Code asking for permission as usual.

## Results

2026-11-19, Claude Code 2.1.328, plugin 0.11.0, 3 runs per case and arm, judge Haiku 5.5.
Score = share of scored graders passed. Cost is Claude Code's list-price estimate per run.

| Model | Case | With plugin | Without | Cost per run (with / without) | Time per run (with / without) |
|---|---|---|---|---|---|
| Opus 5.5 | open | 1.00 | 0.97 | $1.15 / $0.43 | 4.8 / 2.3 min |
| Opus 5.5 | exclude | 0.93* | 0.97 | $0.96 / $0.39 | 3.7 / 1.8 min |
| Opus 5.5 | large (41 sources, ~75k words) | 1.00 | 1.00 | $1.50 / $0.75 | 6.0 / 3.2 min |
| Opus 5.5 | resume (planted mistakes) | 1.00 | 1.00 | $1.29 / $0.50 | 5.4 / 2.3 min |
| Haiku 5.5 | open | 1.00 | 1.00 | $0.11 / $0.03 | 4.9 / 2.2 min |
| Haiku 5.5 | exclude | 0.97 | 0.97 | $0.05 / $0.03 | 2.9 / 1.7 min |
| Haiku 5.5 | large | 1.00 | 1.00 | $0.22 / $0.05 | 6.2 / 3.4 min |
| Haiku 5.5 | resume | 1.00 | 1.00 | $0.05 / $0.03 | 3.6 / 2.5 min |

\* Two of three failures were the article mentioning the studio's official denial of the fake
acquisition, which the skill's rules allow (a confirmed fact). That grader was too strict and
has been replaced by a judge that accepts the denial.

Protocol indicators (plugin arm, 12 runs per model): on Opus every run fired the skill,
generated `final.md` with `build_final.py`, ran the report, ended with a clean quote check, and
(where graded) rated the PS5 rumor 3+ as one origin; in the resume case every run fixed both
planted rating mistakes and appended to the fact-check log instead of rewriting it. On Haiku
the same, except one run (exclude case) in which Haiku didn't invoke the skill.

**What this shows.** On a given set of saved sources, both models write an accurate article
without the skill, even with 41 long pages, a Japanese-only release delay, a rumor retold ten
times, similarly named games and a resumed session. So the skill doesn't improve the accuracy
of the final text in these conditions. What it adds is the process and the trail: saved
originals, a rated claim for every fact, origins, a fact-check log, verified quotes and a
generated final copy, all reliably produced (23 of 24 plugin runs). It costs about 2-3x more and
takes about twice as long. Live web research is measured below.

How the earlier numbers were corrected: the first run reported a +6% advantage for the
plugin, which came from a too-narrow "no invented facts" reference that penalized footnote
details. The judge now gets the full source texts.

### Live web research (`shenmue-live`)

2026-11-20, same setup, 3 runs per arm. Task: research from scratch how much Shenmue (1999)
cost and where the figures come from, and write a ~600-word article with sources. Scored in the
harness: the budget is presented as disputed and attributed. Measured after the run by
[verify_live.py](verify_live.py): every cited URL opened, every quote (5+ words) looked up on the
cited pages, and each quote that wasn't found checked by hand.

| | Opus 5.5 with | Opus 5.5 without | Haiku 5.5 with | Haiku 5.5 without |
|---|---|---|---|---|
| Score (budget disputed and attributed) | 1.00 | 1.00 | 0.67 / 1 / 1 ** | 1.00 |
| Cited URLs per article | 26 | 9 | 12 | 5 |
| Cited URLs that open (rest: closed to bots) | 61 of 78 *** | 23 of 26 | 34 of 37 | 14 of 16 |
| Quotes from sources | 16 | 40 | 5 | 32 |
| ... found on a cited page | 16 (3 via their Japanese originals) | 36 (4 via originals) | 5 | 29 |
| ... not checkable: cited page closed to bots | 0 | 4 (Forbes, Destructoid; read via the archive, live URL cited) | 0 | 1 |
| ... altered or not from a page the model read | 0 | 0 | 0 | 2 |
| Cost per run | $2.76 | $1.07 | $0.17 | $0.09 |
| Time per run | 7.7 min | 3.8 min | 4.6 min | 1.5 min |

Not counted as quotes: the author's own phrases in quotation marks (one per arm in most
articles) and a quoted label paraphrased as "ever made" for the source's "ever developed" (Opus
with plugin).

\*\* The failed run attributes both figures ("$70 million: press reports, first source not
traced"; "$47 million, including marketing: Suzuki, 2011") in text and in a table; on reading
it, this looks like a judge false negative, but the score is left as measured.

\*\*\* Counting the 2 Wayback links that timed out on the first check and opened on a re-check.
The 17 that don't open are live URLs of sites closed to bots; the plugin cites each source's
live URL together with its archive copy, and the archive copies open.

The two problem quotes (Haiku without plugin): "require massive amounts of time and manpower"
where the page says "requires", and "recouped by VF3 & 4", attributed to forum posts that the
article itself says returned HTTP 403 and were not read, so the quote came second-hand.

**What this shows.** Neither model invented quotes on this topic. Without the plugin, quotes
sometimes point to pages the model never read (it cites the live URL of a page it read through
the archive, or quotes a source it couldn't open), and the weaker model altered one quote. With
the plugin, every source quote was checked against a saved original and opens at a cited URL,
at about 2.5x the cost (Opus) or 2x (Haiku).


### Intake (`silent-hills-intake`)

2026-11-20, 3 runs per arm. A vague request in Ukrainian, with no "don't ask me": "I want to
write an essay about why Silent Hills was cancelled, help me with the research, work in
research/silent-hills". Plugin evals are single-turn, so this case checks only the first turn:
does the model check with the user before researching?

| | Opus 5.5 with | Opus 5.5 without | Haiku 5.5 with | Haiku 5.5 without |
|---|---|---|---|---|
| Asks or shows a plan/settings before researching | 3 of 3 | 0 of 3 | 3 of 3 | 0 of 3 |
| Replies in Ukrainian | 3 of 3 | 3 of 3 | 3 of 3 | 3 of 3 |
| Settings saved in `STATE.md`, no sources saved before approval | 3 of 3 | | 3 of 3 | |
| Cost per run | $0.27 | $1.51 | $0.01 | $0.07 |
| Time per run | 0.8 min | 3.2 min | 0.8 min | 1.3 min |

With the plugin, the reply is one round of questions: languages the user reads (pointing out
that many first-hand sources are Japanese), audience and length, how to treat rumors, depth,
time frame. Without it, the model does a full research pass on its own assumptions and
proposes the essay's argument.

### Live, contested, non-English (`silent-hills-live`)

2026-11-20, 3 runs per arm. Task, in Ukrainian: research how and when Silent Hills was
cancelled, what Konami, Kojima and del Toro said, where the explanations come from and what
rumors followed, then write a ~800-word article in Ukrainian with sources. The sources are in
English and Japanese; the real reasons were never stated officially; the later rumors were
denied. Scored: the article exists, is in Ukrainian and cites web sources; the timeline is
right; the reasons are attributed, not presented as Konami's; the 2020 Sony and Abandoned
rumors are labeled with their denials; at least one Japanese source is cited.

| | Opus 5.5 with | Opus 5.5 without | Haiku 5.5 with | Haiku 5.5 without |
|---|---|---|---|---|
| Score | 1.00 | 1.00 | 0.90 * | 0.86 |
| Cites a Japanese source | 3 of 3 | 3 of 3 | 2 of 3 | 0 of 3 |
| Cited URLs per article | 35 | 18 | 6 | 10 |
| Cited URLs that open (rest: closed to bots) | 84 of 106 ** | 43 of 54 | 18 of 18 | 23 of 31 |
| Quotes in the source's language, found on a cited page | 21 of 21 | 16 of 16 | 8 of 8 | 4 of 5 *** |
| Translated quotes (into Ukrainian) | 22 | 42 | 8 | 14 |
| ... with the original shown and checked | 16 | 0 | 8 | 0 |
| Protocol followed (skill, generated `final.md`, clean quote check) | 3 of 3 | | 2 of 3 | |
| Cost per run | $4.67 | $1.66 | $0.19 | $0.12 |
| Time per run | 14.7 min | 4.9 min | 4.7 min | 2.6 min |

Article titles in quotation marks are left out of the quote counts.

\* One run wrote `final.md` by hand, skipped the final quote check, and mentioned the 2020
insider rumors and the Abandoned theory without their denials (the third run failed only on
citing no Japanese source, like all three runs without the plugin).

\*\* 22 live URLs of sites closed to bots; their archive copies, cited next to them, open.
Two quotes first looked missing because the Wayback Machine refused requests during the check;
both are on the pages on a re-check.

\*\*\* Del Toro's "one of the most moronic things I've ever witnessed" is real (a tweet,
2016-12-02) but isn't on any page the article cites.

**What this shows.** On a contested topic with sources in other languages, Opus writes an
accurate, well-attributed article either way. Haiku finds Japanese sources more often with
the plugin. The clear difference is again verifiability: without the plugin, none of the 56
quotes translated into Ukrainian comes with its original, so a reader has to find each source
and translate it back to check it; with the plugin, 24 of 30 do, checked against a saved copy.
The other 6 (Opus) are short translated phrases in quotation marks, written outside the quote
syntax, which the quote check doesn't see (since 0.12 it lists them for review). The faithfulness of translations without an
original wasn't checked. Cost: about 2.8x (Opus) and 1.6x (Haiku).
