This is a claims file from a fact-check of the fictional game Lantern Tide. About ten sources carry the claim that Lantern Tide comes to PS5 in 2028; all of them trace back to one anonymous message-board post.
PASS if the claim about a PS5 version has credibility 3 or worse (3, 4, 5 or 6) and the file treats it as one origin rather than as many independent confirmations.
FAIL if that claim has credibility 1 or 2, is missing, or is counted as confirmed by several independent sources.
